## ✨ What is ThumbForge AI?

**ThumbForge AI** is an AI-powered web application built for YouTube creators, marketers, and content teams.

It simplifies the thumbnail creation process by allowing users to generate visually engaging thumbnail concepts from their content ideas.

Instead of starting from a blank canvas, creators can quickly turn an idea into a thumbnail concept and iterate on it.

### 🎯 Built for

- 🎬 YouTube Creators
- 📹 Video Editors
- 📈 Content Creators
- 📱 Social Media Managers
- 🧑‍💻 Indie Creators
- 🚀 Personal Brands

## 💻 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/arish096/ai-youtube-thumbnail-generator.git
```

### 2. Open the project

```bash
cd ai-youtube-thumbnail-generator
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local development URL shown in your terminal.
